# TPA 기반 자산배분 노트

전체 포트폴리오 접근법(TPA, Total Portfolio Approach)으로 개인 투자자의 자산배분을 정리한 문서 모음입니다. 부동산·소득·연금·금융자산을 하나의 대차대조표로 보고, 자산 이름이 아니라 위험 요인을 기준으로 배분을 판단합니다. 원화로 소비하는 한국 투자자를 기준으로 합니다.

## 읽는 순서
1. **위험 요인 지도 → 경제 국면별 자산 배분**: 무엇에 대비할지
2. **주식·채권 상관관계 점검 → 동적자산배분 점검**: 채권의 역할과 운용 방식
3. **자녀 계좌 운용 원칙**: 자녀 명의 계좌가 있을 때
4. **대표 ETF**: 상품을 고를 때

## 참고
* ETF 정보와 데이터는 2026년 10월 기준입니다. 국내상장 ETF는 종목명 변경과 신규 상장이 잦으므로 매수 전에 다시 확인합니다.
* 세법·제도(ISA, 연금, 증여공제 등)도 2026년 10월 기준이며 바뀔 수 있습니다.
* 동적자산배분 점검의 백테스트 스크립트는 `backtest/` 폴더에 있습니다. 내려받은 데이터(`backtest/data/`)는 저장소에 올리지 않습니다.
* 개인 참고용으로 정리한 자료이며, 특정 상품의 매수·매도 권유나 투자 자문이 아닙니다.
